# AgriShield

AgriShield is an early-warning system for agricultural commodity supply anomalies. 

## Project Structure
- `frontend/`: React + Vite + TypeScript frontend.
- `backend/`: FastAPI + Python backend.

## Getting Started

### Backend
```bash
cd backend
python -m venv venv
source venv/bin/activate  # On Windows use `venv\Scripts\activate`
pip install -r requirements.txt
python main.py
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
